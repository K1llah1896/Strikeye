# Design: 下层对齐持久化

## Decisions

1. **存在 SQLite 而不是配置文件**：项目已有迁移体系与 DataRoot 概念，per-map 偏好天然是键值表；也让 `viewprefs` CLI 与 UI 共享一份真值。
2. **默认值必须逐像素等于原状态**：`SetLowerView(0,0,1)` 时走原来的 `Scale` 快路径，保证既有截图/测试不受影响，也让"重置"成为真正的 no-op。
3. **钳制在仓库层**：偏移 ±512 像素、透明度 0.1–1.0。越界数据无法把下层推出画布或彻底隐藏，UI 崩坏的可能性被数据层挡掉。
4. **透明度下限不取 0**：0 会让下层完全不可见，用户会以为"切换失效"；0.1 仍能看出结构。
5. **两个画布共享同一份设置**：回放与热力图用的是同一张地图，分别记忆会让人困惑。

## Risks

- 偏移是画布像素而非世界单位，画布尺寸变化时视觉偏移比例会变；当前画布尺寸固定，后续若支持缩放需要改为归一化偏移。
