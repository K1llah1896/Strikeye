## Context

标注要满足三个约束：位置必须可复现（不能用像素坐标，否则换图/换缩放就漂）、要能跨会话保留、要与现有 2D 回放共用投影。callout 数据集正好给出稳定的世界坐标盒子，`maps.WorldToRadar` 负责投影。

## Goals / Non-Goals

**Goals**

- 一键在区域上打点，2D 回放立刻能看到。
- 标记持久化，CLI 与 UI 共享同一份数据。
- 与回放无关：任意回合切到区域页都能看到全部标记。

**Non-Goals**

- 不做自由笔刷/任意线条（mygo 拿不到画布内指针坐标，属工具链限制而非设计取舍）。
- 不做逐帧标注或时间轴对齐。
- 不做跨 demo 的全局标记（标记属于某场比赛）。

## Decisions

1. **标记锚定 callout**：世界坐标由数据集提供，天然稳定；用户选的是"哪个区域"而不是"哪个像素"。
2. **唯一键 (demo, round, callout)**：重复点击是幂等 upsert，不会堆出重复标记；round 0 表示整场。
3. **颜色白名单**：只接受 amber/red/green/blue，非法值回退 amber——画布只实现了这四色。
4. **画布绘制放在帧渲染之后**：即使没有回放帧（未加载/空回合）标记也可见。
5. **写库放后台 goroutine**：点击不阻塞 UI，完成后 `applyPins` 重绘。

## Risks / Trade-offs

- 只能按区域标注，无法标"这个墙角"。折中：note 里写清楚。
- 每张图 callout 粒度为数据集定义（10 张图），未覆盖地图无法标注。
