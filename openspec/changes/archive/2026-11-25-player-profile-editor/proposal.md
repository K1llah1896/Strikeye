# 选手档案编辑（GUI）

## 为什么

选手档案（显示名 + 备注 + 标签）只有 `strikeye-cli profile` 能写。资料库卡片能显示标签、关键词能搜到标签，但用户没有任何入口去加标签——这个能力对 GUI 用户实际是不可达的。

## 变什么

1. 分析页选手抽屉新增「档案」一行：显示名、备注、标签（逗号分隔）+「保存档案」按钮，保存后回显状态。
2. 草稿按 SteamID 加载与重置：展开某位选手时从存储读一次，切到另一位选手时换草稿，不把上一位的文字带过去。
3. 保存走 `profile.Save`，与 CLI 完全同一条写路径（空字段保留旧值、标签归一化）。

## 影响

- capability：`match-library-and-analysis-ui`（ADDED「Player profile editor」）。
- 无新表：复用迁移 v3 的 `player_profiles`。
- 存储不可用（只读/初始化失败）时显示只读提示，不抛错。
