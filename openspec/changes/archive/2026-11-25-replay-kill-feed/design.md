# Design: 击杀信息条

## Decisions

1. **不扩展 `.cs2rpl`**：死亡事件已带 tick/双方 slot/爆头/坐标，武器可以从击杀者最接近的弹道事件推出来（真实 demo 里击杀前必有该玩家的 `weapon_fire`）。省掉一次格式版本升级，也避免历史缓存失效。
2. **固定 tick 窗口而非 tickRate 自适应**：`killFeedWindowSeconds=6` 乘 `tickRate`（缺省 64），窗口跨地图与解析器一致。
3. **面板放右上角且半透明**：地图内容集中在中心，右上通常空旷；半透明底让雷达细节仍可读。
4. **名字由视图传入**：画布不持有数据库或选手表，`SetSlotNames` 复制一份 map 以避免 UI 线程与渲染线程竞争。
5. **过期击杀自动消失**：只显示 `tick - death.Tick <= window` 的条目，避免旧回合残留；最多 4 行防止遮挡。

## Risks

- 击杀者当 tick 没有弹道事件（例如刀杀、被队友补掉）时武器名为空，属可接受的降级。
