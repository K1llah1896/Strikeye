# 设计

## 决策

**为什么写同一个 cfg 路径**：CLI 的 `gsi` 子命令、GSI 横幅与这张卡必须指向同一个文件；不同路径会让用户遇到"配置生成了但不生效"。

**为什么卡片里不启动接收端**：接收端需要长期驻留并在退出时清理 `.part` 镜像；放进 UI 的 goroutine 会随窗口关闭而丢流。卡片只做配置生成 + 状态展示，接收端交给 `strikeye-cli gsi` 或 agent 守护。

**为什么 30 秒判活**：GSI 的 `heartbeat` 是 10 秒，30 秒可以容忍两次丢失；再长会把"中途退出"误显示成 live。

## 风险

- 监听地址没有校验端口号范围（`host:port` 形式即可），错误值会被写进 cfg，CS2 侧静默失败。
- token 明文写进 cfg（Valve 的格式如此），文件权限 0644，与 CLI 一致。
