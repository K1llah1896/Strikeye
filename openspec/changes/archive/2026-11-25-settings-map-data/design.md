# 设计

## 决策

**为什么放在设置页而不是各分析页**：下载是全局缓存操作，不随 demo 变化；放在区域控制页会让用户以为"只影响这一场"。分析页仍保留"缺数据"的提示文案，但补上"去设置页下载"的指向。

**为什么后台 goroutine + 超时**：`navs.zip` 7.7MB、解压后单图 5–20MB，在慢网下能拖几十秒。渲染线程不能等；`mapDataBusyTimeout = 10 分钟` 防止挂死的请求永远占着状态条。

**为什么状态条显示张数与大小而不是逐文件进度**：`EnsureNavs` 的进度回调是逐图文字，直接打到状态条会闪；汇总成"已缓存 N 张"更适合设置页。

## 风险

- 首次下载全部官方图会写 100–200MB 到缓存目录，没有配额提示。文案里写明"全部官方图"即隐含这一点。
- 无凭据的 raw.githubusercontent.com 与 GitHub Releases 在某些网络下不可达；失败只在状态条显示错误，不做重试。
