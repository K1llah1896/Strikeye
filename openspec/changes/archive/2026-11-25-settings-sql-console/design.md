# 设计

## 决策

**为什么放设置页而不是新标签页**：控制台是低频工具，放进主导航会挤占分析流程；设置页本来就是"高级与运维"的落脚点。

**为什么只显示 20 行**：渲染不是虚拟列表，几百行会把整页滚动区拉爆。完整结果通过 CSV 导出，路径与其它导出统一。

**为什么用 `Select` 预设而不是文档**：用户不记得列名（`strikeye_rating` 还是 `rating`？`match_players` 还是 `players`？），一个下拉把正确答案摆在眼前。

**为什么校验失败要清 `sqlBusy`**：校验发生在点击瞬间，如果不复位，界面会一直显示"查询中…"，用户会以为卡死。

## 风险

- `match_events` 的 `event_type = 'kill'` 取值依赖解析器的写入命名；预设写错会返回 0 行而不是报错，用户可能误以为没数据。
- CSV 导出没有并发保护：连点两次会生成两个文件（时间戳秒级，可能覆盖）。属于可接受的取舍。
